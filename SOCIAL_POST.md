## Description (Long Form)

### What is whoop-as?
A WHOOP MCP server that brings your fitness data directly to Claude Code, Claude Desktop, and claude.ai/code.

**Stop copy-pasting your metrics. Start asking Claude.**

---

## Key Features
```
✅ 6 powerful WHOOP tools
  • Recovery scores & HRV tracking
  • Sleep analysis & performance
  • Workout strain & metrics
  • Daily cycle summaries
  • Profile & body measurements
  • One-call daily snapshot

✅ Interactive setup wizard
  (No developer account required)

✅ Works everywhere
  • Claude Code (CLI)
  • Claude Desktop (Mac/Windows/Linux)
  • claude.ai/code

✅ 100% Private
  Your data stays on your machine
```

---

## Installation (Copy-Paste)
```
pip install whoop-as
whoop-as-setup
claude mcp add --transport stdio whoop --scope user -- python -m whoop_mcp.server
```

### Reddit/Dev Community
```
🏃 I Built whoop-as: A WHOOP MCP Server for Claude

Hi folks! I just released whoop-as, an open-source MCP server that lets you access your WHOOP fitness data directly in Claude.

**What it does:**
- Fetch your recovery scores, HRV, sleep analysis, and workout data
- Ask Claude questions about your fitness metrics in real-time
- No manual copy-paste or data juggling

**Setup is super simple:**
```bash
pip install whoop-as
whoop-as-setup  # Opens browser for OAuth
claude mcp add --transport stdio whoop --scope user -- python -m whoop_mcp.server
```

**Example usage:**
```
Claude: "Show me my recovery and sleep for this week"
Claude: "What was my hardest workout this month?"
Claude: "Should I go heavy or recovery today based on my metrics?"
```

**Why I built this:**
I wanted Claude to understand my fitness context without me having to manually share data every time. Now it's just automatic.

**Tech:**
- Python + FastMCP
- WHOOP v2 API
- Works on Mac, Linux, Windows
- Published on PyPI

GitHub: https://github.com/anmshar/whoop-as
PyPI: https://pypi.org/project/whoop-as/

Feedback welcome! Star if you find it useful ⭐
